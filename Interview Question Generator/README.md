# Interview Question Generator

A simple Python application that displays predefined interview questions based on the selected job role.

## Objective

The objective of this project is to help users prepare for interviews by providing role-based interview questions through an easy-to-use command-line application.


## Supported Job Roles

* Python
* Data Science
* Web Developer

Additional roles can be added by extending the question database.

## Technologies Used

* Python

## How It Works

1. Display available job roles.
2. Accept the user's selected role.
3. Search the predefined question database.
4. Display the corresponding interview questions.
5. Inform the user if the selected role is unavailable.

## Installation

Clone the repository:

```bash
git clone https://github.com/maharukhh/interview-question-generator.git
cd interview-question-generator
```

## Run the Project

```bash
python main.py
```
