# Language Learning App

A simple Python-based language learning application that helps users learn basic vocabulary through an interactive quiz.


## Objective

The objective of this project is to provide a beginner-friendly language learning experience by allowing users to practice common words and test their knowledge through a quiz.
## Supported Languages

* Spanish
* French

More languages can be added by expanding the language dictionary.

## Technologies Used

* Python

## How It Works

1. Display the available languages.
2. Allow the user to choose a language.
3. Present vocabulary words one by one.
4. Ask the user for the English meaning.
5. Check the answer and provide instant feedback.
6. Display the final quiz score and performance feedback.

## Installation
