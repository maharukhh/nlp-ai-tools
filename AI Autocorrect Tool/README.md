# AI Autocorrect Tool

A simple Python application that suggests the closest matching word from a predefined dictionary using Python's `difflib` library.


## Objective

The objective of this project is to demonstrate a basic autocorrect system that helps users identify the correct spelling of misspelled words.


## Technologies Used

* Python
* difflib

## How It Works

1. Store a predefined list of valid words.
2. Accept a word from the user.
3. Compare the input with the available words.
4. Find the closest matching word.
5. Display the best suggestion.


## Installation
